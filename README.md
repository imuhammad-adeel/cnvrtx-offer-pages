# CNVRT X Front Office: offer pages

The Astro source of the site: one main sales page, twelve problem pages, five legal pages, onboarding and thank-you.

## Commands

- `npm install`
- `npm run dev` starts the site at http://localhost:4321
- `npm run build` builds to `dist/`
- `npm run studio` builds and sends the finished pages to the GoHighLevel AI Studio project

See `AGENTS.md` for how the two repositories fit together.
