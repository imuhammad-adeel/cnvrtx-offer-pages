# CNVRT X Front Office: offer pages

A finished Astro site: one main sales page, twelve problem pages, five legal pages, onboarding and thank-you.

- AI tools: read `AGENTS.md` first. The site must be reproduced exactly, not redesigned.
- `reference-build/` holds the finished pages as plain HTML, CSS and JS.

## Commands

- `npm install`
- `npm run dev` starts the site at http://localhost:4321
- `npm run build` builds to `dist/`
- `npm run reference` builds and refreshes `reference-build/`
